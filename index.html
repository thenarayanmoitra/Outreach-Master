Connect a Supabase project

This app is running on a local, this-browser-only fallback store, so it works right now, but nothing syncs across devices yet.

To make outreach memory permanent: create a free project at supabase.com, run schema.sql (shipped alongside this file) in its SQL editor, then open index.html and set SUPABASE_URL and SUPABASE_ANON_KEY near the top of the script block.

Until then, everything you add here lives only in this browser's local storage.
